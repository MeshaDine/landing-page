Everyone at the table sees the same bill

  1. 01

    Scan the table’s QR code

    Every table gets its own code. The phone camera opens your menu in the browser, already set to the right table. Nothing to download.

  2. 02

    Start a table, or join with a PIN

    The first guest types a nickname and starts the table. They get a 4-digit PIN, and everyone else at the table joins with it.

  3. 03

    Fill one shared cart

    Everyone browses and adds dishes to the same cart from their own phone, with notes like “less spicy”. The host places the order for the table.

  4. 04

    Orders and the bill, live

    Order more rounds any time. Every guest sees what the table has ordered and the running bill, so there are no surprises at the end.

FAQ

Questions owners ask us.

Do my guests need to download an app?

No. Scanning the QR code opens the menu in the phone’s browser. It works on any recent Android phone or iPhone.

How do friends at the same table order together?

The first guest starts the table and gets a 4-digit PIN. Everyone else joins with that PIN and adds to the same cart from their own phone.

Who sends the order?

The guest who started the table places the order for everyone, so a half-finished cart never goes out by accident. The table can order as many rounds as it likes.

Can guests ask for changes to a dish?

Yes. Each item has a special instructions field, like “less spicy” or “no onion”.

Will the menu match my restaurant?

Yes. The menu shows your restaurant’s name and colours, and every table gets its own QR code.
